# Security policy

Report security or privacy problems privately through GitHub: open this repository's **Security** tab and choose **Report a vulnerability** (https://github.com/dantonoli/interview-prep-desk/security/advisories/new). Please do not open a public issue for them.

Include what you found, how to reproduce it, and the plugin and version (`version` in the plugin's `.claude-plugin/plugin.json`). Reports are answered on GitHub. There is no bug bounty.

Supported versions: the latest release of each plugin.
